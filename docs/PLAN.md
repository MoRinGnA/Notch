# Notch 기능 계획

Windows 상단 상태 아일랜드입니다. 접힘과 펼침 두 상태가 있으며, 이 문서는 디자인 원칙과 현재 동작, 제거된 기능, 남은 계획을 기록합니다.

## 디자인 원칙

- **노치 모양 변화로 정보를 표시합니다.** 미디어 재생과 시스템 상태에 따라 같은 노치가 모양을 바꿔 보여줍니다.
- **HUD 스캔라인:** 미디어가 없을 때 펼친 시스템 HUD에 정적인 가로 스캔라인 오버레이를 표시합니다. 미디어 패널에서는 노치 전체 오버레이를 숨깁니다.
- **상태 점 없음:** 배터리 점 표시는 폐기했습니다. 배터리는 접힌 노치 오른쪽의 `LOW` 배지·충전 번개와 펼친 화면 문구로만 알립니다. CPU 온도는 펼침 HUD에서 보여줍니다.
- **포인트 컬러:** 시계/HUD와 배터리 `LOW`는 고정 `--notch-accent`(#e8833a)를 씁니다. 미디어 가사 빛살은 현재 표시 중인 세션의 YouTube 썸네일 또는 Spotify 앨범 아트에서 뽑은 대표색을 쓰고(일시정지 중에도 유지), 미디어가 사라지거나 유효한 표지색이 없을 때만 고정 주황으로 돌아갑니다. 두 색 계열은 서로 독립입니다.
- **표시 우선순위:** 활성 미디어 세션이 있으면 미디어 패널을 보여주고, 미디어가 없으면 시계와 시스템 상태 HUD를 보여줍니다.
- **접힌 노치 미디어 표시 (결정):** 재생 중(Playing)인 세션이 있을 때 접힌 노치가 가로로 길어져도 됩니다. 크기 고정 제한은 이 항목에서 풀어 둡니다.

## 현재 상태 (완료)

- 투명 프레임리스 창 900x340. 접힘은 154x40(가사에 따라 최대 860), 펼침은 미디어 또는 HUD 화면 600~860x280
- **펼친 화면:** 내비게이션 없이 미디어 상세 또는 시스템 상태 HUD를 표시합니다. 어떤 화면을 띄울지는 활성 미디어 세션 여부에 따라 결정합니다.
- **중복 실행 방지:** 앱을 두 번 열면 같은 설정 파일을 서로 덮어쓰므로 두 번째 실행은 기존 창을 보여주기만 하고 종료한다.
- 노치 실제 크기에 맞춰 Windows 클릭 영역을 제한(`setShape`). 투명 영역은 클릭이 통과합니다.
- 앱 아이콘: `scripts/make-icon.mjs`로 노치 눈 모양 아이콘(`assets/icon.ico`·`icon.png`·`tray.png`)을 코드로 그리고, exe·트레이·창 아이콘에 쓴다(`npm run icon`으로 재생성). 바탕화면 exe의 이름·설명·회사명도 채워져 있다.
- 시스템 트레이 메뉴에서 호버 펼침·전체화면 숨김·펼침 단축키 설정과 Notch 종료
- 평면 눈 애니메이션
- 펼침 HUD: 시계·날짜, CPU 온도(85°C 이상은 흑백 반전 경고), 데스크탑 GPU 사용률, 날씨와 IP 기반 도시명 (미디어가 없을 때는 HUD만 표시). 온도는 LibreHardwareMonitor/OpenHardwareMonitor 센서를 먼저 쓰고, 없으면 Windows 열 구역 중 가장 높은 값을 쓴다. 읽을 수 없으면 `--`로 둔다.
- **볼륨 채널 (완료):** 시스템 마스터 볼륨을 한 줄짜리 미니 계기판으로 줄여 따로 행을 잡지 않습니다. HUD에서는 맨 아래 정보줄 왼쪽에 `TEMP`·`GPU`, 오른쪽에 `VOL`+레일+판독값+`M` 스위치를 나란히 두고, 미디어 패널에서는 재생 버튼 줄을 3칸 그리드로 나눠 버튼은 정중앙, 계기판은 오른쪽 끝에 앉힙니다(레일 폭 80~88px). 두꺼운 막대 대신 1px 기준선과 1px 채움, 10%마다 짧은 눈금(50%마다 긴 눈금), 끝에 3x2 머리를 붙인 1px 바늘, 3자리 판독값, 음소거는 흑백이 반전되는 작은 `M` 스위치로 값을 읽습니다. 채움과 바늘에만 포인트 컬러를 쓰고(미디어 재생 중에는 표지 대표색, HUD에서는 고정 주황), 눈금·판독값·플레이트는 흑백으로 둡니다. 음소거하면 포인트 컬러가 빠지고 판독값이 가라앉으며 반전은 `MUTED` 플레이트 하나에만 줍니다. 막대를 클릭하거나 끌어 조절하고, 방향키 ±2(Shift ±10)·Home/End·`M` 키를 지원합니다. 마우스를 올리면 목표 지점에 반투명 바늘이 서고 판독값이 목표 숫자로 바뀝니다. 음소거 상태에서 볼륨을 만지면 Windows처럼 소리가 되살아납니다. 조작은 화면에 즉시 반영되고(전환 효과 없이 기계식으로 튐), 펼친 동안에는 300ms 간격으로 시스템 값을 다시 읽어 미디어 키·다른 앱의 변경도 바로 따라옵니다. 시스템에 쓰는 동안에는 조회를 멈춰 늦게 도착한 옛 값이 방금 바꾼 값을 되돌리지 않게 했고, 커서 모양은 바꾸지 않습니다.
- **볼륨 제어 경로:** Windows Core Audio(`IAudioEndpointVolume`)를 C#으로 감싼 PowerShell 도우미 한 개를 펼친 동안만 유지하고 stdin/stdout으로 `get`·`set`·`mute`만 주고받습니다(Add-Type 컴파일 비용 때문에 호출마다 새 프로세스를 띄우면 드래그가 끊깁니다). 접힌 노치에서는 조회하지 않고, 60초 동안 요청이 없으면 도우미를 종료합니다. 값을 읽지 못하면 `---`로 두고 마지막 값을 유지합니다.
- 미디어 패널은 Windows 미디어 세션이 있을 때 표시합니다. 브라우저의 유튜브와 온라인 강의 등도 포함합니다.
- 드래그 선택 차단 (`user-select: none`)
- **접힌 미디어 표시:** 왼쪽에 가수(8px 대문자)·제목(11px), 1px 세로 구분선, 오른쪽에 현재 가사(12px). 곡의 가장 긴 가사 줄 폭으로 노치 폭을 한 번 정하고 곡 동안 유지하며, 긴 가사는 말줄임하지 않고 창 폭 안에서 늘어납니다. 가사 줄이 비면 직전 가사를 유지합니다.
- **펼친 가사:** 같은 곡의 가장 긴 줄이 두 줄로 접히지 않도록 펼친 폭도 계산해 넓힙니다. HUD로 바뀌면 가사 폭을 물려받지 않고 기본 600px로 돌아옵니다. 미디어를 펼친 화면에서는 `NOTCH` 문구를 숨기고 충전·배터리 부족일 때만 그 자리에 표시합니다.
- **가사 조명 효과:** 펼친 가사 위로 미디어 표지에서 추출한 대표색 빛줄기가 지나갑니다(흑백·저채도 표지는 고정 주황으로 폴백하며, 표지색은 HSL 밝기를 최소 82%로 보정해 검은 배경에서도 보이게 합니다). 속도는 고정 시간이 아니라 해당 줄의 실제 재생 구간에 묶여 있고, 줄 시작에 왼쪽 끝·줄 끝에 오른쪽 끝에 닿습니다. 재생 위치에서 계산한 마스크 위치를 250ms마다 선형 보간으로 갱신하며, 일시정지하면 그 자리에 멈춥니다. 좌우 빛 밴드는 조금 좁히되 펼친 화면은 접힌 화면보다 넓게 퍼지도록 조정했습니다.
- **가사 조회:** 펼침 여부와 무관하게 곡이 바뀌면 조회합니다(접힌 화면에서도 가사 표시).
- **접힌 가사 조명:** 접힌 노치 가사에도 같은 미디어 대표색 빛살이 흐릅니다. 펼친 가사와 같은 재생 위치 계산을 그대로 쓰고, 빈 줄(간주)에서는 이전 가사는 남기되 빛은 두지 않습니다. 빛 밴드 폭을 조금 줄였습니다.
- **여닫힘 애니메이션:** 폭·높이는 과하게 튀지 않도록 짧게 전환하고, 패널이 짧게 따라 나타납니다. 모션 감소 설정을 지원합니다.
- **트레이 설정:** 트레이 아이콘 메뉴에서 바로 바꿉니다. `마우스 올리면 펼치기`·`전체화면에서 숨기기` 체크박스와 `펼침 단축키` 하위 메뉴(`Ctrl+Alt+N`·`Ctrl+Shift+N`·`Ctrl+Alt+Shift+N`·`사용 안 함`)가 있고, 바꾸면 즉시 적용되어 앱을 다시 실행할 필요가 없습니다. 값은 `%APPDATA%\Notch\settings.json`에 저장되어 다음 실행에도 유지됩니다(파일은 저장용이며 직접 고칠 필요 없음).
- **화면 동작:** 마우스를 140ms 올리면 펼쳐지고, 벗어나면 320ms 뒤 접힙니다. 클릭으로 고정/해제, 전역 단축키 `Ctrl+Alt+N`으로도 고정/해제합니다. 버튼 포커스는 자동 접힘을 막지 않습니다. 노치 밖에 마우스가 있을 때 고정을 풀면 다음 호버는 바로 열립니다.
- **전체화면 숨김:** 3초마다 앞쪽 창이 모니터를 덮었는지 보고 숨깁니다. 최대화 창은 제외하므로 작업표시줄을 자동 숨김으로 써도 노치가 함께 사라지지 않습니다.
- **접힌 빛의 줄 전환:** 줄이 바뀔 때 빛 요소를 새로 만들어, 오른쪽에서 왼쪽으로 되돌아가지 않고 다음 줄 왼쪽 끝에서 바로 시작합니다.

## 제거됨

- **메모·타이머·스톱워치·포모도로:** 사용자가 다시 쓰지 않을 기능으로 결정해 화면, 트레이 메뉴, IPC, 저장·알림 코드를 제거했습니다. 기존 `%APPDATA%\Notch\notes.json` 및 `%APPDATA%\Notch\timer.json` 파일은 삭제하지 않고 보존합니다.
- **AI 상태 (Freebuff):** 사용자 요청으로 제거했습니다. 상태 점, 가장자리 선 애니메이션, CTX·PRJ 표시, Freebuff DB 읽기 코드가 모두 빠졌습니다. Freebuff 작업 중 여부는 로컬 DB 신호로 판정할 수 없었습니다.
- **배터리 점:** 색이 있는 점으로 배터리 상태를 보여주는 안은 폐기했습니다(사용자 결정). 노치 모양을 바꾸지 않는 현재 방식(`LOW` 배지·충전 번개·펼친 화면 문구)만 사용합니다.

## 구현 순서

### 1. 미디어 (최우선 표시)
- **데이터 출처:** Windows 미디어 세션(GSMTC). 스포티파이 데스크탑 앱과 브라우저의 유튜브 탭이 모두 여기에 재생 정보를 등록합니다.
- **스포티파이 (실측):** 제목, 아티스트, 앨범, 앨범 아티스트, 트랙 번호, 썸네일(앨범 아트)을 받습니다.
- **유튜브 (실측, 웨일 브라우저 탭):** 제목은 영상 제목 그대로(`[가사/해석/lyrics]` 꼬리표 포함), 아티스트는 채널명, 앨범은 없고 썸네일은 영상 썸네일입니다.
- **세션 선택:** 미디어 세션이 여러 개 잡힙니다. 재생 중(Playing)인 세션을 우선 표시합니다.
- **재생 소스 직접 선택:** 재생 세션이 둘 이상이면 NOW 화면에 앱/탭 버튼을 나열하고(같은 앱의 여러 탭은 `CHROME·1`처럼 번호를 붙임), 사용자가 고른 세션을 자동 선택보다 우선합니다. 고른 세션이 사라지면 조용히 자동 선택으로 돌아가고 버튼 줄은 숨깁니다.
- **가사 출처 (결정):** LRCLIB 등 공개 가사 DB에서 제목과 아티스트로 조회합니다. 미디어 세션 API에는 가사가 없습니다. 키 필요 여부와 정확한 API는 구현 전에 확인합니다.
- **판본 고르기:** 같은 곡이 원문(한글)과 로마자 표기로 따로 올라와 있어 정확 조회만으로는 로마자가 잡힐 수 있습니다. 정확 조회 뒤 검색 API도 한 번 더 확인해, 점수가 같으면 한글 가사 → 줄별 시각이 있는 가사 → 재생 길이에 가까운 가사 순으로 고릅니다. 레이블 채널이라 아티스트를 못 얻으면 제목 앞부분(`aespa 에스파 'Supernova'`)에서 아티스트를 추정하고, 아티스트를 모를 때는 제목과 재생 길이(±5초)로 맞춥니다.
- **펼친 패널 (결정):** 가사 중심으로 표시합니다. 제목, 아티스트, 앨범(있을 때만)은 가사와 함께 보여주고, 재생/일시정지, 이전, 다음 버튼을 붙입니다.
- **싱크 가사 강조 (결정):** 애플뮤직처럼 재생 위치에 맞는 줄을 크고 밝게 표시하고, 나머지 줄은 흐리게 둡니다. 현재 줄은 패널 가운데에 오도록 부드럽게 스크롤합니다. 싱크 가사(LRC 타임스탬프)가 없는 곡은 평문 가사를 그대로 보여줍니다. 일시정지 중에는 위치를 멈춥니다.
- **가사가 없을 때 (결정):** "가사를 찾지 못했습니다." 문구 대신 유튜브 검색 썸네일을 가사 영역에 꽉 차게 깔아 보여줍니다. 썸네일을 못 받으면 앨범 아트로 돌아가고, 그것도 없으면 비워 둡니다.
- **가사 포인트 조명 (완료):** 앨범 아트나 영상 썸네일에서 추출한 대표색의 빛살을 가사에 표시합니다. 색을 추출할 수 없거나 유효하지 않은 표지색이면 고정 주황색을 사용하며, 노치 주변 글로우 효과는 사용하지 않습니다.

### 2. 미디어 / 시스템 상태
- 미디어가 없을 때 펼친 HUD에 시각·날짜, CPU 온도, 데스크탑 GPU 사용률, 날씨를 표시합니다.
- 다음 일정 표시는 캘린더 연동이 필요해 보류합니다.

### 4. 후순위 (조사 또는 결정 후 진행)
- 사용량 링: 무료 사용 잔량을 읽을 로컬 데이터가 있는지 먼저 확인합니다.
- 로보 화면 질문: API 키 설정 방식을 먼저 정합니다.
- 캐릭터 꾸미기: 디자인 결정이 먼저 필요합니다.
- 파일 드롭: 파일을 섬에 끌어 놓으면 경로를 기록하거나 지정 위치로 옮깁니다.

### 5. 보류
- 블루투스 오디오 연결·기본 출력 전환: 이미 페어링된 기기의 재연결이 한 번에 되지 않는 경우가 많아(사용자 경험상 한두 번 더 눌러야 연결됨) 실패를 보장할 수 없다는 이유로 넣지 않기로 결정했습니다. Windows에는 드라이버에 연결을 "시도"하라고 요청하는 `KSPROPERTY_ONESHOT_RECONNECT`만 있고 성공을 보장하지 않습니다.
- 승인 (Allow/Deny): Freebuff 쪽 외부 응답 인터페이스가 확인되지 않았습니다.
- 로보 파일 자동 수정: 노치의 역할을 넘고 안전 문제가 있어 제외를 권합니다.
